Repositorio contenedor de mis proyectos realizados en el campus [42 Madrid](https://42madrid.com/) como parte del proceso formativo en programación intensiva.

Aquí encontrarás los ejercicios y proyectos que abarcan desde el desarrollo en C hasta estructuras de datos, manejo de memoria, señales, algoritmos y más.

## 📁 Estructura de proyectos

- [`Libft`](./Libft) — Librería básica en C desde cero
- [`ft_printf`](./ft_printf) — Implementación personalizada de `printf`
- [`get_next_line`](./GNL) — Lectura de líneas desde un `file descriptor`
- [`Born2beroot`](./Born2beroot) — Proyecto de virtualización y seguridad
- [`Minitalk`](./Minitalk) — Comunicación entre procesos con señales
- [`Push_swap`](./Push_swap) — Algoritmos de ordenamiento con stacks
- [`So_long`](./So_long) — Mini juego con renderizado 2D usando `minilibx`
- [`Grademe-42Exam`](./Grademe-42Exam) — Repositorio de práctica para exámenes

## 🚀 Sobre mí

Soy estudiante de 42 Madrid, apasionado por el bajo nivel, la seguridad y el desarrollo backend. Este repositorio representa el recorrido que he seguido en el cursus, con cada proyecto superando al anterior en complejidad y desafío.
